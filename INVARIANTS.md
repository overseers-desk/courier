# Invariants

Rules whose breach is a design change, not a fix; changing one is the owner's decision.

- Nothing in `research/` is canonical product spec, only the basis for it: the folder holds verbatim user voices and dated competitive snapshots that feature copy derives from, so reading a survey or quotebook entry as a commitment inverts the authority direction and turns an observation into a requirement nobody made.
- The version is defined in `pyproject.toml` and mirrored, not independently set, in the package modules: two unrelated version claims ship two answers to "what is installed". Documentation carries no hardcoded version numbers, which every release would falsify.
- The Homebrew formula is not in this repo; it lives in the `overseers-desk/homebrew-od` tap and points at the PyPI sdist. Install metadata kept here as well would give the release two homes that drift.
- A library call takes its configuration and its `WORLD_AS_OF` bound as arguments and reads neither the environment nor any file under the home directory itself; the config file, `.env` and environment variables are read by the loader the command uses (`load_config`) and by the two entry points, which pass the results in. A core that read them on its own would make every program importing courier depend on whatever sits in its host's home, and a cron job with no such setup could not use the library at all.
- Importing the package has no side effect: no `.env` is loaded, no logging is configured and no path is computed from the home directory at import time. A host program's environment and logging are its own, and an import that changed them would act on the host before the host had called anything.
- The local index is a deployment option, not courier's shape: an account can be configured without one, and is then served over IMAP. A feature whose behaviour is worked out only for the indexed path leaves the unindexed accounts an open question at build time and a surprise at run time, so what the feature does without the index is settled while designing it, whether that is the same behaviour, a degraded one, or a declared refusal.
